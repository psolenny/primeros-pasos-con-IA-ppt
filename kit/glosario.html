Glosario de bolsillo

↓ descargar PDF

Las trece palabras que necesitas para entender cualquier conversación sobre IA en el trabajo.

empresa
Quien construye la IA.
Anthropic · OpenAI · Google
modelo
El “cerebro” entrenado. Es el motor.
Claude Opus · GPT · Gemini
asistente / agente
Modelo + instrucciones + herramientas, listo para una tarea. El chat responde; el agente actúa.
Claude · ChatGPT · un bot de atención
interfaz
Por donde lo usas.
web · escritorio · móvil · Excel · WhatsApp
herramienta
Lo que le permite hacer cosas, no solo hablar.
buscar · leer un PDF · enviar un correo
prompt
Lo que le escribes. La primera fuente de contexto.
“Resume este correo en 3 viñetas”
contexto
Todo lo que la IA tiene sobre la mesa al responder: lo que escribes, lo que le das a leer y sus instrucciones.
mismo modelo + mejor contexto = mejor resultado
alucinación
Cuando la IA inventa un dato, cita o fuente con total seguridad.
regla: todo dato se verifica
prompt injection
Órdenes escondidas en un texto que la IA lee y que puede obedecer.
el CV con letra blanca
proyecto
Un espacio para un tema de trabajo con sus propias instrucciones y archivos. Cada chat que abres dentro ya arranca con ese contexto.
“Correos a clientes” · “Reportes de ventas”
skill
Un manual de procedimiento (instrucciones + plantillas + ejemplos) que el asistente carga cuando la tarea lo pide.
minutas · informes · propuestas
rutina
Una tarea que el asistente hace igual cada vez, a demanda o programada.
“resumen de mi lunes”
ventana de contexto
La memoria de trabajo de una conversación. Tiene fondo: lo del medio se diluye.
un chat por tema
